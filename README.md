📱 Grama-Waste Tracker

A smart Android application designed to improve waste collection efficiency in rural areas by providing real-time tracking, notifications, and citizen reporting tools.

---

🚨 Problem Statement

Waste collection in villages is often irregular. Residents have no reliable way to know when the waste collection vehicle ("Kachara Gaadi") will arrive, leading to garbage accumulation and unhygienic conditions.

---

💡 Solution

Grama-Waste Tracker solves this by providing:

* 📍 Live tracking of the waste collection vehicle
* 🔔 Arrival alerts before the vehicle reaches users
* 📸 Reporting system for illegal dumping ("Blackspots")
* ♻️ Waste segregation guidance (Dry/Wet waste)

---

✨ Features

📌 Live Map Tracking

* Real-time location of the waste collection vehicle
* Smooth movement using GPS updates

🔔 Arrival Alerts

* Notification when the vehicle is nearby (e.g., 5 minutes away)

📸 Blackspot Reporting

* Upload images of garbage piles
* Automatically captures GPS location
* Helps Panchayat monitor and act quickly

♻️ Waste Guide

* Visual icons to educate users on waste segregation

---

🔄 User Flow

1. User opens the app
2. Views live map with tractor location
3. Receives alert when vehicle is nearby
4. Reports garbage issues if found
5. Uses waste guide for proper disposal

---

🛠️ Tech Stack

* Language: Java / Kotlin
* IDE: Android Studio
* Maps: Google Maps API
* Database: Firebase Realtime Database
* Notifications: Firebase Cloud Messaging (FCM)
* Location Tracking: GPS / Location Services

---

⚙️ Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/grama-waste-tracker.git
   ```

2. Open in Android Studio

3. Sync Gradle

4. Add your **Google Maps API Key**

5. Connect Firebase project

6. Run the app on emulator or device
